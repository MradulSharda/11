## Prompt 2 – Direct insert-if-short Implementation (Task S2.b)

Using `my-length` and `my-map`, implement Task S2.b:
`(insert-if-short x lst n)`

Rules from the specification:
- `x` is an atom (number or symbol).
- `lst` is a (possibly nested) list of atoms and sublists.
- `n` is an integer >= 0.
- `insert-if-short` inserts `x` at the front of every list whose original length was strictly less than `n` (`< n`), at every level of nesting.
- The length of a list is measured on the original list before any insertion.
- The top-level list is treated like every other list.
- Empty list `()` has length 0; if `0 < n`, `()` becomes `(list x)`.
- Atoms inside lists are left untouched.
- Important: `list?` is forbidden! To check if an element is a sublist, use `(or (pair? elem) (null? elem))`.
