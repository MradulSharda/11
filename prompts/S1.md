## Prompt 2: Accumulator-Based Traversals (No `append`)

For tree traversals, `append` and `reverse` are strictly forbidden by the assignment rules. That means we cannot use naive recursive appends like `(append (inorder left) (cons val (inorder right)))` because that is quadratic and uses forbidden built-ins.

Instead, let's write three pure, accumulator-based helper functions that run in linear O(N) time using just `cons`:

1. `(tree->inorder-acc tree acc)`: traverses inorder (left, node, right), prepending elements onto `acc`.
   - If empty: return `acc`.
   - Otherwise: traverse `right` with `acc`, `cons` the node's value, then traverse `left` with that result.
   - Wrapper: `(tree->inorder tree)` calling `(tree->inorder-acc tree '())`.

2. `(tree->preorder-acc tree acc)`: traverses preorder (node, left, right), prepending onto `acc`.
   - If empty: return `acc`.
   - Otherwise: traverse `right` with `acc`, traverse `left` with that result, and finally `cons` the node value.
   - Wrapper: `(tree->preorder tree)` calling `(tree->preorder-acc tree '())`.

3. `(tree->postorder-acc tree acc)`: traverses postorder (left, right, node), prepending onto `acc`.
   - If empty: return `acc`.
   - Otherwise: `cons` the node value onto `acc`, traverse `right` with that accumulator, and then traverse `left`.
   - Wrapper: `(tree->postorder tree)` calling `(tree->postorder-acc tree '())`.
